1. Оператор и статус проекта

Оператором обработки данных демонстрационного проекта Merra Booking является Рамазанов Адиль Даниярович, физическое лицо, осуществляющее разработку проекта в Республике Казахстан.

Город: Костанай, Республика Казахстан.

Контакт по вопросам обработки данных: team@merrabooking.me.

Merra Booking — независимый pre-launch/demo-проект. Разработчик — физическое лицо; регистрация ИП/ТОО пока отсутствует. Сайт не является полноценным коммерческим SaaS-сервисом: формы регистрации, подключения партнёров и оплаты отключены. Демонстрационный бот не предназначен для реальных клиентских, медицинских, платёжных или иных чувствительных данных. До включения соответствующих функций информация об операторе, поставщиках и способах обработки будет обновлена.

2. Какие данные обрабатываются

Сайт merrabooking.me

  • технические данные, необходимые для безопасности и работы сайта;
  • данные, которые пользователь добровольно отправляет по email.

Аналитика, рекламные пиксели и сторонние трекеры не используются. Шрифты сайта размещены локально и не загружаются из Google Fonts.

Демонстрационный WhatsApp-бот

  • номер WhatsApp;
  • имя профиля, если оно передаётся WhatsApp;
  • текст сообщений;
  • выбранная услуга, дата и время демонстрационной записи;
  • технические метаданные и журналы безопасности в минимальном объёме.

3. Цели обработки

  • демонстрация сценария записи;
  • ответы на сообщения;
  • тестирование WhatsApp-интеграции;
  • техническая поддержка;
  • защита от спама, злоупотреблений и атак;
  • обработка запросов на удаление данных.

Данные не используются для рекламы, продажи баз или маркетинговых рассылок.

4. Хранение

Публичный сайт сам по себе не хранит диалоги. Данные демонстрационного WhatsApp-бота хранятся ограниченное время в зависимости от действующей конфигурации demo-контура и удаляются по запросу (см. страницу удаления данных). Конкретный автоматический срок хранения будет опубликован до запуска production-функций. Технические журналы могут храниться ограниченный срок, необходимый для защиты сервиса и расследования инцидентов.

5. Получатели и внешние сервисы

  • Meta / WhatsApp — передача и доставка сообщений; часть технических данных обрабатывает Meta по своим условиям;
  • Cloudflare — DNS, проксирование, защита и технические журналы;
  • GitHub Pages (GitHub, Inc., США) — хостинг статических страниц сайта;
  • AI-провайдер (Claude API от Anthropic) — только после отдельного включения ИИ-функции: могут передаваться текст диалога и справочные данные заведения, необходимые для ответа; номер телефона не должен передаваться в AI-запросе. До запуска такой функции её обработка и сроки хранения будут описаны дополнительно.

База данных демонстрационного контура размещена на инфраструктуре оператора в Казахстане.

6. Передача данных

Внешние поставщики могут обрабатывать данные на инфраструктуре за пределами Казахстана (США и глобальная edge-сеть), поскольку это фактически определяется расположением их инфраструктуры.

7. Cookies и локальное хранение

Сайт не использует необязательные аналитические, рекламные или маркетинговые cookies и не создаёт пользовательский аккаунт. GitHub Pages и Cloudflare могут применять строго необходимые технические механизмы безопасности, управляемые соответствующими поставщиками. В интерфейсе сайта нет трекеров или рекламных пикселей.

8. Права пользователя

  • запросить сведения об обработке данных;
  • попросить исправить данные;
  • запросить удаление demo-диалога;
  • прекратить дальнейшее взаимодействие с ботом;
  • направить обращение на team@merrabooking.me.

Для защиты от запросов посторонних лиц может потребоваться подтверждение принадлежности номера или диалога.

9. Изменения

Политика может изменяться; новая версия публикуется на этой странице. Дата вступления в силу — 11 октября 2026 года, последнее обновление — 11 октября 2026 года.

Privacy Policy

Effective date: October 11, 2026 · Last updated: October 11, 2026 · merrabooking.me

1. Operator and project status

The operator of the Merra Booking demonstration project is Ramazanov Adil Daniyarovich, an individual developing the project in the Republic of Kazakhstan. City: Kostanay, Republic of Kazakhstan. Data-protection contact: team@merrabooking.me.

Merra Booking is an independent pre-launch/demo project. The developer is an individual; no sole-proprietor or company registration exists yet. The site is not a full commercial SaaS service: registration, partner onboarding and payment forms are disabled. The demo bot is not intended for real client, medical, payment or other sensitive data. Operator, subprocessor and processing details will be updated before any such features are enabled.

2. Data processed

Website: technical data required for security and operation; data the user voluntarily sends by email. No analytics, ad pixels or third-party trackers are used. The site's display fonts are self-hosted and are not loaded from Google Fonts.

Demo WhatsApp bot: WhatsApp number; profile name if provided by WhatsApp; message text; selected service, date and time of the demonstration booking; minimal technical metadata and security logs.

3. Purposes

Demonstration of the booking flow, replying to messages, testing the WhatsApp integration, technical support, protection against spam and abuse, and handling deletion requests. Data is not used for advertising, database sales or marketing campaigns.

4. Storage

The public website itself does not store dialogues. Demo bot data is stored for a limited time according to the active demo configuration and deleted on request (see the data deletion page). The specific automatic retention period will be published before production features are launched. Technical logs may be kept for a limited period required to protect the service and investigate incidents.

5. Recipients and external services

  • Meta / WhatsApp — message delivery; some technical data is processed by Meta under its own terms;
  • Cloudflare — DNS, proxying, protection and technical logs;
  • GitHub Pages (GitHub, Inc., USA) — hosting of the static site pages;
  • AI provider (Claude API by Anthropic) — only after the AI feature is separately enabled: dialog text and venue reference data needed for a reply may be sent; the phone number should not be included in the AI request. The processing details and retention period will be documented before this feature launches.

The demo database is hosted on operator infrastructure in Kazakhstan.

6. Data transfers

External providers may process data on infrastructure located outside Kazakhstan (USA and the global edge network), as determined by the actual location of their infrastructure.

7. Cookies and local storage

The site does not use optional analytics, advertising or marketing cookies and does not create user accounts. GitHub Pages and Cloudflare may apply strictly necessary technical security mechanisms controlled by those providers. The site has no trackers or advertising pixels.

8. User rights

  • request information about data processing;
  • request correction;
  • request deletion of a demo dialogue;
  • stop further interaction with the bot;
  • contact team@merrabooking.me.

To protect against third-party requests, proof of ownership of the number or dialogue may be required.

9. Changes

This policy may change; new versions are published on this page. Effective date: October 11, 2026; last updated: October 11, 2026.
